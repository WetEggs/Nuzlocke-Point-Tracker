# Nuzlocke-Point-Tracker
Nuzlocke Point Tracker is a tool designed for a unique variant of the Nuzlocke challenge, where players earn points by defeating trainer Pokémon. These accumulated points can be strategically spent on “perks” for either Pokémon or the player, unlocking new potentials and abilities. The system encourages thoughtful decision-making by requiring players to manage a limited pool of points, adding a layer of calculated strategy to the gameplay experience.

Points Earned (per Pokemon):
Regualr Trainer- 2 Points
Gym Trainer (Trainers INSIDE Gym)- 3 Points
Boss Trainer (Gym Leader, Rival, Evil Team Leader/Admin, E4/Champion)- 5 Points

*Each perk is only usable once per Pokemon*

Pokemon Perk System:
"👜 Held Item": 20 Points, allows Pokemon to hold items.
"💿 TM": 40 Points, allows usage of TMs. Can be extended to HMs depending on player.
"✨ Evolve": 60 Points, allows Pokemon to evolve, when active, works for multiple stages of evolution.
"💪 Stat Boost": 80 Points, can make one of the Pokemon's IVs 31.
"🧬 Nature Change": 80 Points, Can change Pokemon's Nature.
"💊 Ability Capsule": 100 Points, available after Gym 4, can swap to a different ability that the Pokemon has access to.
"🩹 Revive": 150 Points, available after Gym 6 can revive a Pokemon (must be added prior to death).

*Each perk is only usable once per playthrough*

Trainer Perk System:
    "Dupes clause removal", "🚫", 50 Points, adds Dupes/Species Clause to playthrough.
    "Turn on EXP Share (Gen 6+)", "⚡", 75 Points, allows usage of EXP Share item when it becomes a Key Item. You may extend this to games that it is a held item.
    "Re-pair Pokémon (Soul Link)", "🔗", 75 Points, specifically fdr Soul Link challenges. Allows the re-pairing of a set of Pokemon.
    "Same Type pair (Soul Link)", "💠", 125 Points, specifically for Soul Link challenges. Allows a pair to share a primary typing.
    "Use of one item in battle", "🎒", 150 Points, allows usage of one item in battle, in each battle, for the rest of the playthrough.
    "Switch Mode", "🔁", 200 Points, changes game from "set" mode to "switch" mode.
    "Free Encounter", "🎲", 300 Points, awards a free encounter in the desired area for the player. Must be used immediately upon purchase.
